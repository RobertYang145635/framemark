## 根因与修法

1. **示例重复**：IR 的一行参数由多个文本节点拼成（`@exif=@{focal}mm`、`@exif=f/@{aperture}`…），
   缺 EXIF 时每个节点各是一条空值行，App 却给每格塞了同一份整行示例。
   修法在引擎：`textSlots[].sample` 用一份标准样张 EXIF（按款式分厂商机型）跑同一个
   token 模板逐节点算；App 用它画示例、也用它在探针里复现真实行布局。
   地点 / 自定义文字这类「正常照片也没有」的行不预填（不编内容）。
2. **不能修改**：`textSlotControls()` 用 `isCurrentTextSlot()`（= 可写且这一帧画出来/显式隐藏）
   当门，缺 EXIF 的行 `present=false` 直接被判成没有编辑控件；而文字页那边又按
   `isEditableTextSlot()` 把它列为可编辑 —— 两处判据不一致。现在：可写身份就给「替换文字」，
   「显示 / 字号」仍只给画出来的行。

# 0.9.0-rc59

这一版修的是**边框在真实照片上的适配**：OPPO 的 PLD 相框、缺 EXIF 时的文字行、以及
「预填示例」的逐格取值与位置。

## OPPO Polaroid · PLD：按照片比例取对应的框图

PLD 按照片比例从 7 个窗口（1:1 / 4:3 / 16:9 / wide × 横竖）里选几何，但运行时包里只有
一张 4:3 横版框图 —— 其它比例与所有竖图都会把那一张贴上拉伸，框被拉变形、透明窗口对不齐
（3:4 时画布 0.621 却画 0.994 的图，x0.448 / y0.717 非等比）。现在 7 张都在包里，引擎按
照片比例取对应的一张，且只解码这一帧会用到的那张。

- 四组样片实测：画布/框图比例一致（0.9933/0.9936、0.6222/0.6218、0.7644/0.7643、
  1.2987/1.2994），x/y 缩放一致；
- 画幅闸门 `qa/release-gate/frame-aspect.py`（原 glass-aspect.py）新增 PLD 检查：
  旧包 8 条失败，新包 93 项全过。

## 缺失 EXIF 的照片：边框文字可以改了

以前缺 EXIF 的照片套上边框后，文字行只能看、不能改。根因是两处判据不一致：`textSlotControls()`
要求「这一帧画出来了」才给编辑框，而文字页又把这一行列为可编辑。引擎侧实测（e2b + 无 EXIF
照片）写入 `slotText:<节点>` 就能把该行画出来，所以放出「替换文字」即可；「显示 / 字号」仍
只给画出来的行。

## 预填示例：按「这一格本该写什么」逐格给

IR 的一行参数由多个节点拼成（`@exif=@{focal}mm`、`@exif=f/@{aperture}`…），缺 EXIF 时每个
节点各是一条空值行。以前给每格都塞同一整行示例，「小米徕卡 · 4」底栏因此铺了 6 份
`23mm F1.8 1/125s ISO250`。现在引擎按节点算 `sample`（标准样张 EXIF，按款式分厂商机型）：
焦距格显示 `23mm`、光圈格 `f/1.8`、快门格 `1/125s`、ISO 格 `ISO250`；地点 / 自定义文字这类
「正常照片也没有」的行不预填。示例矩形同时修正了坐标系（探针渲染与舞台预览分辨率不同），
不再整体偏左上。

- 全量闸门 `qa/release-gate/prefill-samples.py`：188 张卡（119 IR + 69 手写）× 无 EXIF 照片，
  0 问题；113 个 IR 款式共 394 条缺值行都有逐格示例。

# 0.9.0-rc58 更新说明

对照 rc57。这一版只改玻璃族的「画幅适配」，另加了一道可自动复查的画幅闸门与清理入口。

## 边框

- **玻璃 05**：画布改由构图推导，照片不再被竖幅卡窗裁掉，也不用把参数压到照片上。
  4:3 / 3:4 / 1:1 / 16:9 四组输入都是「照片从画布 45.9% 处开始、卡片 40.9%W / 88.7%H、
  上下留白 5.65%」；画布宽高比随照片走（4:3 照片 → 2.9:1 长条）。rc57 那版在横图上
  照片从 13% 就开始、光圈/焦距/快门三个数值压在照片上。
- **玻璃色卡**：玻璃面板不再因为画布矮而连宽度一起缩。横图也保持 89.2% 通栏；
  面板高度按它自己的 676:310 给，只有很宽的画布才按画面高度 60% 封顶，封顶后色卡网格
  等比缩小——六个色值始终在面板里。
- **液态玻璃**：底部胶囊保持 7.2:1 的形。竖图不再被撑成 4:1 的厚框，字号改按胶囊高度
  换算，「框显厚、字变小」不会再出现。
- **玻璃卡片**：竖图下 `1/400` 不再压到照片上（文字块装不下面板时整组等比缩小）。

## 质量与工程

- 新增玻璃画幅闸门 `qa/release-gate/glass-aspect.py`：四组样片 × 所有用同一模板的卡，
  自动检查「文字不压照片 / 卡片跟照片同比例 / 卡片在画布内 / 玻璃 05 构图占比 /
  色卡标签在面板内 / 胶囊宽高比跨画幅恒定」。用 rc57 的引擎跑会逐条报出这次的回归。
- 清理入口 `execution-ui-v2-20261106/tools/cleanup-workspace.ps1` 修好：默认 dry-run
  只列清单；保留最新 4 次构建 + `latest.json` 里正在发布的那次；老构建的
  `deliverables/` 归档、只删可重建的 `artifacts/` 与 `tmp/`。

## 已知

- 玻璃 05 的输出会是很宽的长条（4:3 照片 → 2.9:1），库里的预览也按这个比例显示。
  这是「构图不变 + 照片不裁」的必然结果；若要更方，只能让卡片改回裁切或接受更大留白。
- golden `liquid-glass/glass-pill-5.png` 是旧画布（1.497:1），不再逐像素可比，
  差异说明记在 `qa/release-gate/known-deviations.json`。

# 0.9.0-rc56 更新说明（对照 rc50）

从 rc50 到 rc56，一共 24 个改动（另有 6 次发布索引提交）。下面按用户能看到的变化整理。

## 边框库

- **经典单行**改成真正的单行：左边「品牌 机型」一行、中间字标、右边参数一行、不显示日期。此前它和「经典双行」的版式完全一样，两张卡渲染出来是同一张图。
- 补齐 7 套缺预览的边框，重出 4 组「两张卡共用同一张样张」的预览。现在 187 套边框每套都有样张，且没有重复。
- **色卡 01 / 02 / 03** 按厂商版式重排：色卡行宽从 130–135% 收回 120%、照片到色卡的间距补到 4%、色卡 03 恢复与 01/02 一致的白边与底距。此前首末两枚圆点和它们的十六进制码会顶到左右边缘，色卡 03 的圆点直接压在照片底边。
- 不按版式设计的卡片不再偷偷裁照片：极简 01/02/04、卡片 02/03/04 恢复整张照片（此前会按抓图时的窗口比例裁掉一条）。电影、比例、16:9 封面这类**按版式设计**的卡片不变。
- 边框库分类校正：一个子类只落在一个大类里。色卡 01/02 归入「色彩边框」；自然诗篇归入「白边边框」；电影 01 与其 02 同组；毕业 01/02 从「厂商边框」移到「印象边框」；FrameMark 精选按「纸感 / 字幕」两组分开归位。

## 尺寸与导出

- 切换尺寸档后，**预览、裁切提示、像素估算和成片一致**：固定比例模板不再出现「预览会裁 408 px、原尺寸导出却是整张照片」；指定长边 1600 时估算不再报 1600×1600 而实际 1600×1226。
- 「原尺寸」按预览的画布导出（照片仍是 1:1，不重采样），不再为了不裁切而退回整张照片。
- 导出命名的**拍摄日期 / 拍摄时间**改用照片自带的 `DateTimeOriginal`，不再用导出那一刻的系统时间；确实没有拍摄时间时，界面明说「文件名用导出时间」。
- Ultra HDR：200MP 照片保留 HDR 导出失败时不再静默存成 SDR（会给提示并说明原因）；封装实现不再把整张 JPEG 逐字节装箱，36.9 MB 主图在 128 MiB 堆上不再 OOM。
- 大幅 HEIC / WebP 导入先查尺寸再解码：超出内存预算时按 2 的幂降采样，避免导入瞬间被系统杀掉。
- **Windows** 补齐 4 套 OPPO 卡（新春限定 · 1002 / 1005、情人节限定 · 1001、品牌 · 3），187 套全部可预览、可导出；此前这 4 套的导出按钮是灰的。

## 文字与占位

- 缺 EXIF 的照片：**缺的那几行仍然可以改**，不再被置为只读或被过滤掉；缺值行用灰色标准参数档占位，位置按实测框画，进过文字页后占位自动消失。此前一律写「待定位」、点框没有高亮。
- 逐卡核对占位文案：不知道这一行是什么角色时，不再猜成「拍摄参数」。
- 手填品牌后（例如没有 EXIF 的照片写「QA54-ALPHA」），Logo 页不再写「按照片品牌 Sony」；只有照片自己带 EXIF 品牌时才这么说，其余情况是「按边框自己的品牌」。

## 设置与导航

- 手机与桌面的**设置图标统一**为同一枚齿轮（桌面此前是细环 + 射线，看起来像太阳）。
- 「关于」里的打赏 / 支持与反馈 / 隐私与权限，返回时先回关于页，不再一步跳回设置首页；左上返回箭头与系统返回键走同一条路。
- 「隐私与权限」从「隐私、权限与许可」里拆出来，是设置页的独立一行；手机上是独立一页。
- 重新打开已保存的工程，当前照片已有的边框会点亮，不再显示「未选择边框」；照片条展开时定位到当前照片，关掉键盘不再跳回第一张。
- 手机相册：折叠下拉 + 竖向列表、按日期分组、吸顶日期标题、可拖动滚动条；相册列表底色改为不透明（此前半透明，网格会透上来）。

## 稳定性

- 修掉「我的 Logo」闪退（嵌套竖向滚动拿到无限高约束）。
- **升级安装不再复用旧解包**：此前 rc54 → rc55 这类「manifest 没变、边框数据变了」的升级会继续用旧数据，编辑器画旧版样式而缩略图已是新版。现在解包身份带随包 zip 的 CRC 与构建标签，升级后会重解一次。
- 系统选择器不可用时给出可操作提示（改走相册导入），不再从点击回调直接闪退。

## 升级提示

- 直接从 rc50 覆盖安装即可，工程、预设、外观都会保留；首次启动会重新解包一次内置边框数据（约 70 MB，一次性）。
- rc56 仍是 QA 签名的预发布包，正式签名版本要另外出。
